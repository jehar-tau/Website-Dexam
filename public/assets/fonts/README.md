# PDF typefaces

The downloadable A4 practice guide embeds local Figtree and Zilla Slab fonts, matching the Discovery design system. No report data is sent to a font or PDF service.

- Figtree source: `https://github.com/google/fonts/tree/main/ofl/figtree`. The variable font was instantiated at weights 400 and 600 with fontTools; the font's outlines, metadata and licence were retained.
- Zilla Slab source: `https://github.com/google/fonts/tree/main/ofl/zillaslab`. Medium (500) and Bold (700) are the original static TTF files.
- Both use the SIL Open Font License 1.1. The accompanying original OFL files are retained here.

The PDF generator subsets these fonts into each report. These assets must remain available at the same origin as the website.
